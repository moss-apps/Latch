### WASM exclusion alternative considered
`pubspec.yaml` asset filters / `packagingOptions { excludes }` do not affect `flutter_assets/packages/pdfrx/assets/...` (generated by Flutter tool, not AGP). Official `pdfrx` tool patches its own `pubspec.yaml`; global `# - assets/` also disables `pdfium.wasm` for web — acceptable because `web/` is absent (Android-only app). To re-enable web: `dart run pdfrx:remove_wasm_modules --revert`.

## 3. APK Splits and `extractNativeLibs`

*Gradle splits:* attempted then reverted (conflict with Flutter’s `ndk.abiFilters`). Phase 1 therefore relies on:

1. **Play AAB** — Play already splits by ABI/density/language via `bundletool` (the 18.5 MB saving above is the Play download saving; no Gradle config needed).
2. **Direct APK** — `flutter build apk --split-per-abi` produces 3 APKs without extra Gradle config:
   - `app-arm64-v8a-release.apk` 67.6 MB (65M) — target for modern devices
   - `app-armeabi-v7a-release.apk` 30.7 MB
   - `app-x86_64-release.apk` 36.4 MB
   - vs `app-release.apk` universal 121 MB (3 ABIs)
   Installer should use split APKs or AAB. Universal APK is for sideload fallback only.

*`extractNativeLibs=false`:* verified in `AndroidManifest.xml:34`. In AAB libs are now `Defl:N` (compressed) vs APK libs `Stored` (APK legacy). Bundletool delivery honors the flag (libs delivered compressed + `extractNativeLibs=false` in manifest merges). No runtime failure: `flutter build` still runs; `flutter analyze` passes.

## 7. Open Decisions & Next Steps (Phase 2)

*from `APP_SIZE_OPTIMIZATION_PLAN.md` Open Decisions:*

1. **Banner quality:** chose lossy WebP q85 at native resolution (851 KB) — visually identical at 20 MP. Alternative: downscale to 1920×1384 q85 → 105 KB, or 1280×922 → 60 KB (99.6% saving). If banner is truly dead (0 Dart refs), **deleting** would save another 0.85 MB. Keeping PNG on disk for README but not bundling is the compromise used.
2. **ABI splits in Gradle:** reverted; `flutter build apk --split-per-abi` is the Flutter-canonical path. If Play Console requires Gradle splits for universal APKs elsewhere, resolve by removing `ndk.abiFilters` via `android.packaging.jniLibs.useLegacyPackaging` or Flutter upgrade — defer to Phase 2 build hardening.
3. **extractNativeLibs trade-off:** false → libs stay compressed → smaller download, marginally slower first load. Keep false for Play; UPX (Phase 2d) would require true.
4. **Remaining Phase 2 candidates not yet done:** R8 `fullMode`, ProGuard `keepclassmembers` narrowing, Go `LDFLAGS -trimpath -extldflags '-Wl,--build-id=none'`, font subsetting — see `APP_SIZE_OPTIMIZATION_PLAN.md` §2.
5. **wasm patch persistence:** CI now patches; local devs must run `dart run pdfrx:remove_wasm_modules` after any `flutter pub get` that re-extracts pdfrx. Consider adding a `Makefile` target or `tool/patch_pdfrx.sh` git hook if web support is never needed.

## 8. Summary

*Delivered size (Play, arm64, SDK29+):* **47.37 MB → 28.88 MB** (−18.5 MB, −39%) — meets 500 MB Play limit with large headroom; primarily from dead-asset re-encode (banner/padlock) and web-only WASM exclusion. No code change, no visual regression, no DEX/R8 regression. Universal APK size appears larger only because Phase 1 now correctly bundles app libs for all ABIs; Play’s per-device delivery (the metric that matters) is decisively smaller.
